## S1 开发者账号实名认证（个人开发者）

**在哪**：浏览器打开 https://developer.huawei.com → 右上角「登录」→ 登录后点头像 →「实名认证」。

**做什么**：
1. 选「个人开发者」（不是企业）。
2. 两种方式任选：①「银行卡认证」（秒过，推荐）②「身份证人工审核」（1–2 个工作日，**8/15 当天做来不及，若还没实名请提前到 8/10 前完成**）。
3. 按提示填姓名、身份证号、银行卡号（银行卡认证仅校验四要素，不扣款）。

**常见坑**：
- ⚠️ **实名是全流程最大的时间坑**。如果走人工审核，会直接吃掉 1–2 天。**建议老板 8/10 前提前把实名做完**，8/15 只做建应用之后的事。
- 认证主体一旦确定不可变更类型（个人→企业需重新注册）。
- 未满 18 岁账号无法实名个人开发者。

**完成标志**：开发者中心头像旁显示「已实名」。

- [ ] S1 完成 ｜ 备注：＿＿＿

## S2 GitHub Pages 隐私政策上线

**在哪**：浏览器 → github.com/ModestyMa/BanBanDefense。

**做什么**：
1. Settings → General → 最底部 Danger Zone →「Change repository visibility」→ 改 **Public**。
2. Settings → 左侧「Pages」→ Build and deployment → Source 选「Deploy from a branch」→ Branch 选 `main`，目录选 `/docs` → Save。
3. 等 1–3 分钟，页面顶部出现绿色横幅「Your site is live at …」。
4. 打开 `https://modestyma.github.io/BanBanDefense/privacy_policy.html`，**手机流量（非 WiFi）+ 电脑各验证一次**能打开。

**常见坑**：
- Pages 首次部署有延迟，刷不出来先等 5 分钟再排查。
- 目录必须选 `/docs` 而不是 `/ (root)`，否则 404。
- 大小写敏感：URL 里 `BanBanDefense` 与仓库名完全一致。
- 仓库转 public 后 `.git/config` 里的访问令牌仍在本地文件，不影响；但**确认仓库内没有任何密钥文件**再转 public（当前快照检查过无密钥，若 8/15 前新增文件需再扫一眼）。

**完成标志**：手机流量下能打开隐私政策页且邮箱显示 938632014@qq.com。

## S3 AGC 创建应用

**在哪**：https://developer.huawei.com/consumer/cn/service/josp/agc/index.html （AppGallery Connect）→「我的项目」旁选「我的应用」→ 左上「发布」页签 →「新建」。

**做什么（逐字段）**：
| 字段 | 填什么 |
|---|---|
| 平台 | **APP（HarmonyOS）** ← 千万别选安卓 APK |
| 设备 | 手机（后续在包内支持多设备，见 S4） |
| 应用名称 | **伴伴**（若提示重名 → 备用名「伴伴-倒数记账番茄」，SPEC_M7 决策 6） |
| 应用分类 | 应用 → **实用工具** |
| 默认语言 | 简体中文 |

然后在项目设置里关联/创建项目，添加应用时填包名：**`com.modestyma.banban`**（复制粘贴，别手打）。

**常见坑**：
- ⚠️ **包名提交后不可修改**，粘贴后逐字符核对一遍（modestyma 无大写、banban 无横线）。
- 应用名称全网查重，「伴伴」两字重名概率较高，被占就直接用备用名，**不要现场发明第三个名字**（文案里已按两个名字都兼容）。
- 建应用 ≠ 上架，此步只是占坑，可以放心先建。

**完成标志**：应用列表出现「伴伴」，状态「准备提交」。

## S4 设备类型核验（决策 4 的现场验证）

**在哪**：AGC → 该应用 →「发布」→「版本信息」页，或上传包后包解析页面。

**做什么**：
1. 查看应用可勾选/自动识别的设备类型是否含：手机 + 平板 + 2in1(PC) + 智能穿戴。
2. HarmonyOS 应用的设备类型由 **上传的 .app 包内 module.json5 自动解析**，一般不需要手动勾选——上传包后（S14 前）在版本信息页确认识别出的设备列表即可。

**判定**：
- ✅ 四类都识别 → 按单包四端继续。
- ❌ 穿戴不识别/报错 → 触发 SPEC_M7 §7 降级预案：**手表砍出本次提审**（DevEco 打包时不勾 wearable module），主包三端先上，手表随 V1.0 补发。**不要为手表拖日期。**

**常见坑**：设备类型问题多半在「上传包解析」时才暴露，所以 S9 打包时建议**先打一个含 wearable 的整包**，解析失败再退回打三端包，两次打包总共多花 10 分钟，别纠结。

- [ ] S4 完成 ｜ 识别到的设备：＿＿＿

## S5 生成发布证书 + 发布 Profile

**在哪**：AGC →「用户与访问」→ 左侧「证书管理」；以及应用的「HarmonyOS 应用」→「HAP Provision Profile 管理」。

**做什么**：
1. 证书管理 →「新增证书」→ 类型选**发布证书**（不是调试）→ 名称随意（建议 `banban-release`）→ 需要上传 CSR 文件（在 S8 的 DevEco 里生成，两步交叉，见下）。
2. Profile 管理 →「添加」→ 类型**发布**→ 选上面的证书 → 选应用 `com.modestyma.banban` → 下载 `.p7b` 文件。

**推荐路径（更省事）**：直接在 DevEco 用**自动签名**（S8 里 File → Project Structure → Signing Configs → 勾 Automatically generate signature，登录华为账号后 DevEco 自动到 AGC 建证书和 Profile）。**先试自动签名，失败再走手动**。

**常见坑**：
- 个人账号发布证书最多 1 个，如果以前建过别的证书占了名额，需先吊销旧的。
- 证书 `.cer`、Profile `.p7b`、密钥库 `.p12` 三件套**下载后备份到网盘**——密钥丢了 App 更新会很麻烦。

## S8 DevEco 配置 release 签名

**在哪**：DevEco Studio → File → Project Structure… → Project → Signing Configs 页签。

**做什么（自动签名路径，推荐）**：
1. 勾选「Support HarmonyOS」+「Automatically generate signature」。
2. 点「Sign In」登录华为开发者账号（就是 S1 实名的那个）。
3. DevEco 自动生成 p12/csr/cer/p7b 并回填，点 OK。

**手动路径（自动失败时）**：
1. Build → Generate Key and CSR → 新建 `.p12` 密钥库（密码记到密码管理器）→ 生成 `.csr`。
2. 拿 `.csr` 去 AGC 完成 S5 的证书申请，下载 `.cer` 和 `.p7b`。
3. 回到 Signing Configs，release 一栏依次填 p12 / p12 密码 / cer / p7b。

**常见坑**：
- ⚠️ 自动签名默认可能只配了 **debug**，务必确认 **release** 一栏也有值（Signing Configs 里有 default/release 区分的下拉）。
- 密钥库密码错一次就报 keystore 相关错误，别猜，重置重新生成。
- 登录弹窗被公司代理/防火墙拦截时换手机热点。

- [ ] S8 完成 ｜ p12 备份位置：＿＿＿

## S9 Build APP(s) 出 release 包

**在哪**：DevEco Studio → Build → Build Hap(s)/APP(s) → **Build APP(s)**。

**做什么**：
1. 确认左下构建变体（Build Variants）里 entry 和 wearable 都是 **release**。
2. Build APP(s)，等待完成。
3. 产物在 `build/outputs/default/` 下的 `.app` 文件（含 entry + wearable 两个 module）。

**常见坑**：
- 选错菜单：Build HAP 只出单 module 的 hap，**上架要的是 .app**。
- release 构建比 debug 慢很多且会做混淆/压缩，第一次可能暴露 debug 没有的报错——**报错原文直接扔给主程序**，这正是留 8/15–9/7 缓冲的原因。
- SVG 图标在 release 打包属于「假设 API 清单」第 2 项，出包成功即验证通过；失败同样回喂主程序。

- [ ] S9 完成 ｜ .app 文件路径：＿＿＿

## S10 真机安装 release 包整包回归

**在哪**：手机真机 + DevEco（用 hdc 或 IDE 直接运行 release 签名版本）。

**做什么**：
1. 手机连电脑，DevEco 选 release 签名配置直接 Run；或 `hdc install` 装包。
2. 按 `CHECKLIST_M6` B 区 + `07_里程碑与验收清单.md` §3.5 整包回归清单跑一遍。
3. 重点自查（审核员视角）：
   - 首次启动是否弹**隐私政策同意弹窗**、点「不同意」是否能退出
   - 设置页「关于」里包名/版本号 1.0.0 显示正确
   - 倒数日提醒（触发一次通知权限申请弹窗，话术是否清晰）
   - 桌面添加宠物卡片正常
   - 「清除全部数据」可用
4. 装完**保持 24 小时观察无崩溃**（SPEC_M7 §6 验收项）——所以 S10 最晚 8/15 当天装上，8/16 提审也来得及，别为了当天提审跳过观察。

**常见坑**：release 签名包和 debug 包签名不同，**先卸载旧 debug 包再装**，否则签名冲突安装失败。

- [ ] S10 完成 ｜ 回归结论：＿＿＿
