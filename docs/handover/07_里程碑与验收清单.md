## 三、模块验收清单（合入 main 前逐项打勾）

### 3.0 工程初始化

- [ ] DevEco 工程创建，包名确定并回填 AI_CONTEXT
- [ ] Git 初始化，.gitignore 含 build/签名文件
- [ ] 空壳 App 真机可安装运行
- [ ] 数据库建库脚本 + 6 张表 + repository 骨架，单元测试通过

### 3.1 倒数日

- [ ] 新建事件 ≤3 步完成，字段齐全（标题/日期/分类/备注）
- [ ] 倒数/正数天数计算正确（含跨月跨年边界）
- [ ] 列表按日期排序、分类筛选正确
- [ ] 编辑/删除后列表与卡片同步刷新
- [ ] reminderAgent 提醒在杀进程后仍能触发（真机验证提前 1 天 + 当天）
- [ ] 免费版第 4 个事件被拦截并提示
- [ ] 深浅色模式无视觉事故

### 3.2 番茄钟

- [ ] 25/5 默认与自定义时长生效，计时误差 <1s/25min
- [ ] 切后台/锁屏计时不中断，结束有通知
- [ ] 中途放弃有确认弹窗，不计入统计
- [ ] 今日/本周统计柱状图数据与记录一致
- [ ] 完成后宠物 exp +2（看 PetState 表验证）

### 3.3 服务卡片宠物

- [ ] 桌面可添加 2×2 与 2×4 卡片
- [ ] 卡片三个调度按钮分别跳转到：快速记账（预填面板）/ 番茄计时 / 新建倒数日
- [ ] 记账/番茄行为后 1 分钟内卡片心情刷新（三档表情）
- [ ] 卡片无网络权限、无越界组件（人工对照卡片受限子集核验）

### 3.4 手动记账

- [ ] 快记从点击到保存 ≤3 步、≤3 秒可完成
- [ ] 账户余额随收支正确增减（含删除流水回滚）
- [ ] 流水按日分组、可编辑可删
- [ ] 月度收支合计与分类环形图 = 流水明细之和（分毫不差）
- [ ] 记账后宠物 exp +1、当日首笔卡片"已记账"

### 3.5 整包回归（上架前 30 分钟清单）
