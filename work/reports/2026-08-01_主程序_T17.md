## 二、调用链变化（before → after）

**Before**：
`CountdownEditPage.onSave()` → `countdownVM.saveEvent(ev, isNew)`
　→ `isNew` 时 `count() >= FREE_EVENT_LIMIT(3)` → `return 'limit'`
　→ 页面收到 `'limit'` → `showLimitDialog()` 弹「免费版最多 3 个倒数日 / Pro 版即将上线」

**After**：
`CountdownEditPage.onSave()` → `countdownVM.saveEvent(ev, isNew)` → 直接 insert/update（无数量判断）
　→ `Promise<void>` 完成 → toast「已添加/已保存」→ `router.back()`

关键代码（after）：
```ts
// CountdownViewModel.saveEvent
async saveEvent(ev: CountdownEventData, isNew: boolean): Promise<void> {
  if (isNew) {
    ev.createdAt = Date.now();
    ev.reminderIds = '';
    const newId = await CountdownRepository.insert(ev);
    ev.id = newId;
    await this.refreshReminders(ev);
  } else {
    await ReminderService.cancelForEvent(ev);
    ev.reminderIds = '';
    await CountdownRepository.update(ev);
    await this.refreshReminders(ev);
  }
  PetCardService.pushToCards().catch(() => {});
  await this.load();
}
```
```ts
// CountdownEditPage.onSave 的 then
countdownVM.saveEvent(ev, this.editId === 0)
  .then(() => {

    });
    router.back();
  })
```
