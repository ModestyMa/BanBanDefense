## 一、核心判断：伴伴已经是"大而全"的底座

基于截图 14 款 App 的全扫描和伴伴当前代码盘点：

1. **品类覆盖**：市面没有任何一款 App 同时覆盖「倒数日 + 番茄专注 + 记账 + 桌面宠物卡片」。滴答清单最宽（待办+番茄+习惯+倒数日），但缺记账且重云端。
2. **伴伴当前已实现**：四模块核心路径全部跑通、四端响应式、宠物联动规则已接入 PetEngine、首启隐私弹窗、设置/隐私页完整。
3. **因此**：8/14 前的目标**不是加新模块**，而是把现有四模块做"美好用"——用情感化（C1）、信任感（C2）、卡片生命感（C3）把"四合一"变成用户愿意传播的产品。

## 三、候选特色详细说明（C1/C2/C3）

### C1 宠物碎碎念（行为联动文案）⭐

**是什么**：宠物根据本地行为数据"说话"。首页宠物区和桌面卡片显示一句动态短语，例如：
- 完成番茄后：「陪你专注了 25 分钟，我骄傲！」
- 当天已记账：「今天的账都记好啦～」
- 连续 3 天没记账：「钱包最近过得怎么样呀？」
- 倒数日临近（≤3 天）：「『XX』还有 3 天，别忘了哦」
- 深夜（23:00 后）打开：「夜深了，明天再战～」

**为什么**：
- 竞品空白独占：官方百变卡片/闪光桌面的宠物是"装饰宠"，拿不到用户的记账/专注/倒数日数据；伴伴 PetEngine 天生坐在四模块数据上，这是**结构性差异**。
- 把"多模块融合"从卖点清单变成**可感知的体验**。
- 商店素材/开发日记有故事可讲（"一只真的认识你的桌面宠物"）。

**怎么做**：
- 文案规则表：产品侧提供 20–30 条文案 + 触发条件，全部 `$r()` 字符串资源。
- 逻辑：`service/PetEngine.ets` 内新增 `getPetSpeech()` 纯函数，符合"联动规则只写 PetEngine"禁令。
- UI：首页宠物区加气泡 Text；卡片 2×4 版加一行文案。
- **估计：2 主程序人日**。
- **风险**：低。纯本地读库+文案映射；最大风险是卡片文案刷新时机，与既有"1 分钟内卡片心情刷新"共用通道。

### C2 零联网隐私徽章 + 隐私宣言页 ⭐

**是什么**：把"零网络权限"从 README 卖点变成产品内可见资产：
- 设置页顶部加"隐私宣言"入口：一页静态图文——「伴伴没有网络权限。你的账单、专注记录、纪念日，从未离开这台设备。不信？去系统设置看看我们的权限列表。」
- 关于页 + 首启隐私弹窗加"0 网络权限"徽章样式。
- 商店截图第一张主打此徽章。

**为什么**：记账竞品差评的最大公约数是广告/上云/暴雷信任崩塌；Forest 事件证明"数据被绑架"是用户最痛的背刺。竞品没有一家**敢**这么写。

**怎么做**：静态页 + 徽章组件，全 `$r()` 资源，无逻辑。
- **估计：1 主程序人日**。
- **风险**：极低。唯一注意点：宣言措辞需与隐私政策文本一致。

### C3 宠物作息钟（卡片昼夜生命感）⭐

**是什么**：宠物卡片按真实时间切换状态：清晨伸懒腰、白天正常三档心情、23:00–6:00 睡觉（Zzz 表情，此时段心情不降级）。参考华为百变卡片"赛博金鱼"的作息设定。

**为什么**：让卡片"活"起来的最低成本方案；与 C1 组合后宠物人设完整（会说话 + 有作息）。

**怎么做**：卡片定时刷新逻辑里加时段判断，PetEngine 输出心情时叠加时段状态；需新增 2–3 套表情资源。
- **估计：2.5 主程序人日**（逻辑 0.5 + 表情素材 1 + 卡片调度与真机验证 1）。
- **风险**：中低。FormExtension 定时刷新次数有系统配额，需验证时段切换刷新策略；素材是主要变数。
